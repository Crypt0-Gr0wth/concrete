# 03 — Frontieres de confiance

Le client chiffre les entrees et dechiffre les sorties ; le serveur execute le programme compile.
La confidentialite du calcul ne masque pas automatiquement tailles, calendrier ou graphe public.
Les clefs d evaluation autorisent le calcul mais doivent tout de meme etre gerees et versionnees.
Les artefacts compiles et parametres font partie du contrat entre client et serveur.
Les erreurs de domaine doivent etre refusees avant chiffrement lorsque possible.
Source : [`tools`](https://github.com/zama-ai/concrete/tree/main/tools).
